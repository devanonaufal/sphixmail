How to Use Sphixmail

Free temporary email for OTP verification and spam-free signups — no registration required.

What is Sphixmail?

Sphixmail is a disposable temporary email service that lets you receive emails without creating an account. Perfect for:

  • Signing up for websites without revealing your real email
  • Receiving OTP verification codes instantly
  • Avoiding spam and unwanted newsletters
  • Testing email functionality in your applications

Fast, private, and completely free. Emails arrive in seconds and are accessible via both web UI and REST API.

Creating an Inbox

Follow these steps to create your temporary inbox:

  1. Open sawith.net in your browser
  2. Choose one of these options:
    • Custom username: Enter your preferred username in the input field
    • Random address: Click the "Random address" button below the input for an auto-generated Indonesian-style name
  3. Select a domain from the dropdown (if multiple domains are available)
  4. If you entered a custom username, click the arrow button (→) on the right side of the input field
  5. Your email address is now ready to use!
Note: Usernames must be alphanumeric (letters and numbers only), with a minimum of 3 characters. Some reserved words like "admin" and "root" are not allowed.

Understanding the Interface

The inbox creation uses a minimal, streamlined design:

  • Input field: Enter your custom username here
  • Arrow button (→): Located on the right side of input — click to create inbox with your custom username
  • Random address button: Instantly generates a random Indonesian-style email address without typing
  • Domain dropdown: Select which domain to use for your email address

Smart Paste Feature

If you paste a full email address (e.g., user@domain.com), the username and domain fields will automatically fill.

Receiving Emails

Once your inbox is created, it automatically checks for new messages every few seconds. You don't need to refresh manually.

New emails appear in the inbox list with:

  • Sender's email address
  • Subject line
  • Relative timestamp (e.g., "2 minutes ago")

Reading Emails

Click any email in the list to view its contents. HTML emails are rendered safely in an isolated iframe to prevent malicious scripts.

Timestamps are displayed in WIB timezone (Asia/Jakarta). Hover over relative time (e.g., "5 mins ago") to see the exact datetime.

Auto-detect OTP Codes

Sphixmail automatically detects verification codes in emails. When an email contains a 4-8 digit OTP, a badge appears with a one-click copy button.

This works for both plain text and HTML emails. Simply click the OTP badge to copy the code to your clipboard.

Deleting an Inbox

To remove an inbox from your session, click the delete icon next to the inbox address. This removes it from your view, but the address remains public.

Important: Inboxes are public by design. Anyone who knows the email address can view its messages. Only use Sphixmail for non-sensitive information like OTP codes and website verifications.

Using the API

Sphixmail provides a REST API for automation, bots, and testing workflows. You'll need an API key to access most endpoints. Contact the admin to request one.

Base URL: https://sawith.net/pub/

For interactive documentation with live testing, visit API Reference.

List Active Domains

GET /pub/domains/[apikey]

Returns all active email domains available for inbox creation.

curl https://sawith.net/pub/domains/YOUR_API_KEY

Response:

{
  "success": true,
  "count": 1,
  "domains": [
    { "domain": "sawith.net", "type": "open", "added_at": "2026-01-01T00:00:00Z" }
  ]
}

Validate Email Address

GET /pub/email/[email]/[apikey]

Checks if an email address is valid and follows username restrictions.

curl https://sawith.net/pub/email/user@sawith.net/YOUR_API_KEY

Response:

{
  "success": true,
  "email": "user@sawith.net",
  "local": "user",
  "domain": "sawith.net",
  "message": "Email is valid and ready to use"
}

Fetch Messages

GET /pub/messages/[email]/[apikey]

Retrieves all messages for a specific inbox. Add ?limit=5 to limit results.

curl https://sawith.net/pub/messages/user@sawith.net/YOUR_API_KEY

Response:

{
  "success": true,
  "email": "user@sawith.net",
  "count": 2,
  "messages": [
    {
      "id": "msg_123",
      "from": "noreply@example.com",
      "subject": "Verify your account",
      "preview": "Your verification code is 123456",
      "body_text": "Your verification code is 123456",
      "body_html": "<p>Your verification code is 123456</p>",
      "received_at": "2026-09-16T12:30:00Z"
    }
  ]
}

Delete a Message

DELETE /pub/message/[message_id]/[apikey]

Permanently deletes a specific message by its ID.

curl -X DELETE https://sawith.net/pub/message/msg_123/YOUR_API_KEY

Response:

{
  "success": true,
  "message": "Message deleted successfully",
  "deleted_id": "msg_123"
}

Get Statistics

GET /pub/stats/[apikey]

Returns usage statistics. Use ?filters=total_messages,unread_messages to filter specific metrics.

curl https://sawith.net/pub/stats/YOUR_API_KEY

Response:

{
  "success": true,
  "data": {
    "total_messages": 1234,
    "current_messages": 87,
    "total_inboxes_created": 567,
    "unread_messages": 12,
    "unread_messages_percentage": "14%"
  }
}

Wait for OTP (Long-Polling)

GET /pub/inbox/[email]/wait-otp

Waits for an OTP email to arrive (no API key required). Ideal for automation scripts and bots.

Parameters:

  • timeout — max wait time in seconds (default: 30, max: 60)
  • subject_contains — filter by keyword in subject
  • after — only return emails after this message ID
curl "https://sawith.net/pub/inbox/user@sawith.net/wait-otp?timeout=30&subject_contains=OTP"

Response:

{
  "found": true,
  "message": {
    "id": "msg_456",
    "from": "noreply@service.com",
    "subject": "Your OTP Code",
    "body_text": "Your code is 654321",
    "received_at": "2026-09-16T12:35:00Z"
  },
  "otp": "654321"
}

Frequently Asked Questions

Question Answer
Are emails stored forever? No. The admin can enable auto-delete to remove old messages automatically.
Can others read my inbox? Yes, if they know the email address. Only use for OTP codes and temporary verifications.
How many inboxes can I create? Limited per session per day (default: 10). This prevents abuse.
Is there a login system? No. Inboxes are tied to your browser session. Clearing cookies removes access.
Is there a mobile app? Not yet, but the website is mobile-friendly and works on all devices.
Why isn't my email arriving? Ensure the domain matches. Wait a few seconds — emails typically arrive within 2-5 seconds.
